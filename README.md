# Porifera mtSSU Atlas

海绵线粒体小亚基rRNA结构图谱：科研图版、可检索记录、结构类型分布与数据下载。

项目网站：https://mitoooool.github.io/porifera-mtssu-atlas/

实验室网站：https://mitoooool.github.io/

## 数据浏览与引用

关键词支持全部字段或指定登录号、物种、属、科、目、纲和组合类型，不区分大小写；属名下拉框精确匹配，并可与纲、目和关键词联合筛选。搜索Agelas的全部字段模式会同时匹配Agelasida等目名，限定属字段或选择Agelas属即可排除其他属。目与属选项依据上游分类筛选更新，清除筛选恢复全部记录；导出TSV始终对应当前结果。

Citation区域提供纯文本和BibTeX切换、一键复制以及.bib下载，明确标注预印本、v1和DOI。自动复制不可用时支持传统复制回退；若浏览器仍拒绝复制，会选中引用文本并提示手动复制。

## 论文与来源

Zhou Yunqian, Gong Lin, Niu Gengyun, Shi Haihe, Li Xinzheng, Robin Gutell & Wei Meicai. *Secondary Structure Diversity of the Mitochondrial Small-Subunit rRNA in Porifera*. bioRxiv v1, 2026-08-30. https://doi.org/10.64898/2026.08.28.747467

该论文为预印本，未经同行评审。本站源于对应作者提交材料，不混入历史数据版本。记录浏览与FASTA依据补充表S2b；类型矩阵依据S2c；dot-bracket模型依据S6。216条分析记录不等于216个物种。图版PNG、XLSX及S6下载文件保持原件不变，TSV、FASTA与WebP为网页派生版本。

## 论文快照与持续维护资源

本站当前展示bioRxiv v1的论文数据快照：216条分析记录及对应图版、统计和下载。新增数据或注释修订不自动改变原论文的样本量和结论，也不覆盖该版本的配套数据。复现预印本v1时，请使用本站保留的对应文件。

独立数据仓储地址暂未确定；网页显示“持续维护资源 · 地址待公布”，不设置空链接，也不将现有图谱冒充最新数据仓储。后续资源应单独标注版本、更新日期与变更，并保留论文对应版本。

## 已知数据核对项

- JX978470：S2b序列为1,003 nt，S6对应序列及结构为1,277 nt，内容亦不相同。本站保留原件并标注差异，关闭此条配对展示及单条STR导出；全量S6保留原始记录并明确提示。其余215条序列忽略大小写后匹配。
- 图2原图部分名称／类型标签与当前S2c写法存在差异；网页类型统计按S2c组织，原图未改写。
- 配对位置图由S6直接生成，横轴是核苷酸序号，连线表示模型中的配对；不是RNA空间构象或常规二级结构布局，不进行新预测。

## 使用与许可

使用研究内容请引用原论文。本仓库不授予通用开放许可或CC许可；图版与数据的再分发请联系论文作者。结构模型和类型矩阵用于比较描述，不直接证明功能、祖先状态或适应性。

## 静态网站

纯HTML、CSS与JavaScript，无需构建、CDN或第三方字体。直接打开index.html即可使用；GitHub Pages从main分支根目录发布。网页在电脑、平板及手机上适配，窄屏表格支持横向滚动。
