- 原手工比对：197条、5390列，原列和gap不变；与项目主页216条论文数据属于不同数据范围，不能混用分母。
- 中心完整模型：OM729629，1068 nt和289个原配对。289对全部映射到原矩阵的578列，合计56933条样本×配对观测。
- 主频率分母始终197；明确ACGU条件频率列出各对的实际分母。筛选只控制显示。
